# Нави

Учебный бот для MAX. Помогает ученику 9 класса выбрать тему индивидуального проекта, написать цель и задачи, составить план и подготовиться к защите. Учитель смотрит работы в админке. Темы, связанные с проблемами региона, добавляет администратор.

Диалог идёт в одной обновляемой карточке. Проект можно отложить и продолжить позже. Команда `/start` предупреждает перед сбросом начатого проекта.

Бот: https://max.ru/ideya_fiks_81_bot

Локальная админка: http://localhost:8000/admin/

Для своей установки логин и пароль администратора задаются при первом запуске.

## Что нужно для запуска на Linux

- Git.
- Docker и Docker Compose с поддержкой `--wait`.
- Интернет для загрузки образов, библиотек и работы API.
- Токен бота MAX `ideya_fiks_81_bot`. Эта версия проверяет имя бота при запуске.
- Ключ OpenAI API с доступом к `gpt-5-mini` и HTTP/HTTPS-прокси для OpenAI.

## Подготовка

Скачай проект:

```bash
git clone https://github.com/TatyanaKon7/NAVI.git
cd NAVI
cp .env.example .env
```

Открой `.env` и заполни:

- `DJANGO_SECRET_KEY` — длинная случайная строка для защиты сессий Django.
- `MAX_BOT_TOKEN` — токен MAX.
- `OPENAI_API_KEY` — ключ OpenAI API.
- `OPENAI_PROXY_URL` — адрес прокси, например `http://LOGIN:PASSWORD@HOST:PORT`.

Настройки локального адреса уже заполнены в примере. Оставь их так:

```dotenv
DJANGO_ALLOWED_HOSTS=localhost,127.0.0.1,[::1]
DJANGO_CSRF_TRUSTED_ORIGINS=http://localhost:8000,http://127.0.0.1:8000
PUBLIC_BASE_URL=http://localhost:8000
```

Домен и сертификат для локального запуска не нужны. Ключи и пароли хранятся только в `.env`, этот файл исключён из Git.

Готовая база находится в `data/navi.sqlite3`. В ней есть таблицы, округа, регионы и начальные настройки. Пользователей и ученических работ в базе нет. Миграции Django сохранены в `bot/migrations`.

## Сборка и запуск

Из папки проекта выполни:

```bash
docker compose up -d --build --wait
```

Команда собирает образы, запускает три контейнера в фоне и ждёт их запуска: `web` — админка, `poller` — события MAX, `worker` — обработка сообщений и заданий. Бот работает через polling.

Сборку и запуск можно выполнить отдельно:

```bash
docker compose build
docker compose up -d --wait
```

Проверь состояние и сообщения контейнеров:

```bash
docker compose ps
docker compose logs --tail=100 web poller worker
```

Создай администратора. Команда попросит логин, почту и пароль:

```bash
docker compose exec web python manage.py createsuperuser
```

## Вход в админку

Открой http://localhost:8000/admin/ или http://127.0.0.1:8000/admin/ на компьютере с Docker. Войди с созданными логином и паролем.

В разделе «Темы регионов» добавь темы для нужных регионов и включи их. Бот предлагает варианты на основе этого банка. Округа и регионы тоже можно менять в админке.

Для проверки работ создай пользователя учителя со статусом персонала и группой «Учителя», затем его профиль в разделе «Учителя». Назначь наставника в карточке проекта перед отправкой работы на проверку.

Открой бота в MAX и отправь `/start`.

Бот получает сообщения через интернет, входящий публичный адрес ему не нужен. Админка и ссылки на загруженные файлы доступны на компьютере с Docker. На телефоне `localhost` указывает на сам телефон.

## Остановка

```bash
docker compose down
```

База, загруженные файлы и проекты сохраняются в локальной папке `data`. Для повторного запуска:

```bash
docker compose up -d --wait
```
